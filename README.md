## Hướng dẫn tải và chạy code local:
1. Tải git
2. Clone code về máy, dùng lệnh `git clone https://github.com/ngkhcutes1tg/Project1_StudentManagement.git` để clone code về máy 
3. Gõ `cd repository` để đi đến thư mục vừa tải code, kiểm tra file bằng lệnh `ls`
4. Chạy code bằng lệnh `g++ main.cpp linkedList.cpp -o main.out` (Nhớ mở terminal vào thư mục Main)
